# Hugging Face 模型极速下载器

一个给 Windows 用的 Hugging Face 模型 / 数据集下载工具。网页界面，本地运行，只监听本机地址，不上传任何数据。

它提供两种下载方式：

- **常规下载** —— 大文件自动多线程分段并行下载（每个文件最多 16 条连接，断线自动重连续传），小文件用官方 `huggingface_hub` 引擎；有逐文件进度、断点续传、历史记录，适合下自己明确要的那几个文件；
- **批量下载** —— 先列出仓库里的全部文件，按条件筛选勾选，再交给 **IDM** 或 **aria2** 多线程下载（也可以转回"常规下载"），适合从一堆仓库里挑文件、下大模型。

两者共用一份配置和 Token；下载源（国内镜像 `hf-mirror.com` / 官方）在左侧导航栏一处切换，两个页面同时生效。

---

## 1. 运行环境

| 项目     | 要求                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 系统     | Windows 10 / 11                                                                     |
| Python   | 3.8 及以上（推荐直接用 Anaconda 环境里那个，实测 3.14 正常）                        |
| 必备包   | `huggingface_hub`（`pip install huggingface_hub`）                              |
| 可选包   | `hf_xet`（勾选"hf_xet 高性能模式"时需要，多连接并发、速度更快但更吃 CPU 和内存）  |
| 可选窗口 | `pywebview`（装了就有真正的原生窗口；没装则用 Edge 的"应用模式"窗口）             |
| 可选程序 | IDM（`IDMan.exe`）、aria2（`aria2c.exe`）——只影响"推送到 IDM / 用 aria2 下载" |

程序默认用 Anaconda 里的 `pythonw.exe` 启动（`C:\Users\<你>\anaconda3\pythonw.exe`），所以 `huggingface_hub` 要装在**这个**环境里。

## 2. 启动

双击 **`启动.bat`** 即可，不会弹出黑色命令行窗口。

- 它会自动在常见位置找 Anaconda / Miniconda 的 `pythonw.exe`；实在找不到时，把完整路径写进 `python_path.txt` 第一行。
- 打不开时双击 **`诊断启动.bat`**：带控制台，先自检再启动，报错会留在窗口里。
- 旧入口 `下载(网页版).bat` 仍然可用（等同于 `启动.bat`）。

命令行也能启动（在 `webui` 目录下）：

```bat
python app.py              :: 正常启动（默认 Edge 应用窗口）
python app.py --browser    :: 用默认浏览器打开，不建独立窗口
python app.py --port 8123  :: 指定端口（默认随机挑一个空闲端口）
python app.py --check      :: 只自检，不开窗口
```

关掉窗口 = 退出程序（还有任务在跑时会再确认一次）。后台不会因为"太久没操作"自己退出，可以放心最小化挂在后台。

## 3. 界面速览

左边是导航栏：**常规**、**批量**，底部是 **源**、**更多** 和 **Token**。点"更多"弹出一个菜单，里面有三项：

- **说明**：解释 HF 网站和 Windows 显示的文件大小为什么不一样；
- **关于作者**：作者信息页（富文本 + 图片，内容在 `关于\关于作者.html`，可以直接改）；
- **关于软件**：版本号、运行环境、依赖、各处路径，以及可自己编辑的版本说明（`关于\关于软件.html`）。

**源**（下载源，两个页面共用）：点一下选 **国内镜像**（`hf-mirror.com`，直连，不走任何代理）或 **官方**（`huggingface.co`，自动走代理：系统代理开着就用它；没开时用系统代理设置里登记过的地址，比如 Clash / v2rayN 的 `[IP]:7890`；代理连不上会在右下角提示）。按钮上的字就是当前的源，选官方时变成琥珀色。切换时正在进行的常规下载任务不受影响，下一次开始下载时生效。

**Token** 直接跳到 Hugging Face 的 Token 创建页；最下面的小圆点是"与后台的连接状态"，变红表示后台已经退出了。

程序不用弹窗打断你：下载完成、出错、"文件还不存在"这类提示都在**右下角**出现一张小卡片，几秒后自己消失；鼠标停上去不会消失，点一下可以展开长内容，同样的提示连续出现只计数不刷屏。全文同时写在"运行日志"里。只有需要你拍板的操作（重新下载、移除记录、清除历史、新建文件夹、修改路径、属性…）才弹窗。

## 4. 常规下载

左边填写参数，右边是进度和历史。

| 字段                         | 说明                                                                                                                                                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 仓库 ID                      | `用户名/仓库名`，也可以直接粘贴网页地址（`https://huggingface.co/用户/仓库/...`）                                                                                                                                          |
| 文件名 / 通配符              | 可选。如 `*.safetensors`、`*.gguf`，留空 = 下载仓库里的全部文件                                                                                                                                                            |
| 保存路径                     | 点"浏览"选择；下载时会自动建文件夹                                                                                                                                                                                             |
| HF Token                     | 受限/私有仓库必填；和批量页共用同一个 Token                                                                                                                                                                                    |
| 下载真实文件（不使用软链接） | 勾选后直接写真实文件，不建指向缓存目录的软链接，方便移动和备份（推荐）                                                                                                                                                         |
| hf_xet 高性能模式            | 需要装 `hf_xet`；速度快但 CPU / 内存占用明显更高                                                                                                                                                                             |
| 同时下载                     | 1~16 个文件同时下载，按网络和硬盘情况调；总连接数 = 同时下载 × 每文件连接                                                                                                                                                     |
| 每文件连接                   | 1~16，**默认 16（最大）**。≥32MB 的文件会自动切成很多小块、同时开这么多条连接下载；某一条连接卡住（服务器不发数据）只影响它自己那一块，20 秒收不到数据就自动断开、从断点重连，整个文件不会停在 0 B/s。填 1 = 只用单连接 |

> **准备时间**：每个文件开始前只需要约 1 秒（向服务器确认文件大小和真正的下载地址），和文件大小无关。临时文件 `.hfdpart` 建成**稀疏文件**：大小一步定好，但不往硬盘写 0（以前要先把整个文件写满 0，20 GB 的文件白等 100 秒）；没写到的地方不占硬盘空间。硬盘不支持稀疏文件时（exFAT / FAT32 / 部分网络盘）自动改成**边下边长**，速度一样。开始前会检查剩余空间，不够就直接提示；"准备中"点停止也能马上停。
>
> "文件名 / 通配符"只填一个明确的文件名（如 `model.safetensors`）时，不拉整个仓库的文件列表；填通配符（`*.safetensors`）或留空（下载全部）时才需要先取列表。
>
> 日志里会写出每一步的耗时（`下载进程已启动（x 秒）`、`文件列表获取完成：… 用时 x 秒`、`⇣ 文件：大小（探测用时 x 秒）`）。觉得慢就看这三行，一眼能看出卡在哪一步。

右侧是统计卡片（文件数、已下载/总大小、**实时速度**、剩余时间、已用时间）、总进度条、文件列表和运行日志。列表最前面是勾选框：勾上文件后，左边的"开始下载 / 停止 / 立即中止"就只对勾选的文件生效（表头点一下全选，`空格` 勾选选中行）。列表**双击**：已完成的文件直接打开，其他打开所在文件夹；**右键**可以打开完整菜单：

打开 · 打开方式… · 打开文件夹 · 继续下载 · 重新下载 · 停止下载 · 复制保存路径 · 从列表移除 · 移除并删除本地文件 · 属性。

快捷键：单击选中，`Ctrl` / `Shift` 多选，`Ctrl+A` 全选，`Delete` 移除，`Enter` 打开，菜单键 / `Shift+F10` 呼出右键菜单。

下载在**独立子进程**里跑，界面不会被拖慢；中途断开后点"继续下载"会续传，不用从头再来。列表本身就是历史记录（存在 `hf_download_history.json`），"清除已完成 / 清除全部历史"只清记录，**不会删文件**；勾选文件后，还可以用这两个按钮只处理勾选的那些：**"从列表移除"**（只清记录，不删文件）和**"移除并删除本地文件"**（会先弹确认框，连同硬盘上已下载的文件一起删掉）。

## 5. 批量下载

左边是仓库列表，右边是这些仓库里的文件清单。

**加仓库**：填 `用户名/仓库名`，多个可用空格分隔，也可以粘贴网页地址；选类型（`model` / `dataset` / `space`）和分支；下载源用左侧导航栏的"源"按钮（两个页面共用）。点"添加并获取"拉取文件清单。单击仓库 = 只看这个仓库的文件，双击 = 重新获取，"刷新选中 / 刷新全部 / 移除"在左下角。

**保存位置**：一个根目录 + "按仓库建文件夹"（默认开，每个仓库一个文件夹，里面的目录结构和 HF 上完全一致）。下面的灰字会实时告诉你实际会存到哪。

**筛选**：所有条件写在一个框里，用空格分隔。同一类条件之间是"或"，不同类之间是"且"。

| 想筛选            | 写法                                                                                   |
| ----------------- | -------------------------------------------------------------------------------------- |
| 文件后缀          | `.safetensors` `*.gguf` `ext:json`                                               |
| 文件名包含        | `fp16` `lora` `*q4_k*`（支持通配符 `*` `?`）                                 |
| 路径 / 文件夹包含 | `dir:vae` `path:unet` `text_encoder/`（带 `/` 的词按路径处理）                 |
| 文件大小          | `>1GB` `<500MB` `>=2G` `100MB~2GB`；只写数字（如 `10gb`、`500`）按 MB 计算 |
| 排除              | `-test` `-.md` `!*demo*`（前面加 `-` 或 `!`）                                |
| 词里带空格        | `"my model"`                                                                         |
| 中文关键字        | `后缀:` `文件名:` `路径:` `文件夹:` `大小:` `排除:`                        |

右上角"常用类型"里有现成预设（模型权重、只要 safetensors、GGUF、配置文件、说明文档、图片、压缩包、数据集）。三个按钮对公司条件做动作：**只勾选符合的 / 追加勾选 / 取消勾选符合的**。打开"实时勾选"后，输入停 0.4 秒就自动只勾选符合条件的（清空条件 = 全部勾选）。

**勾选与路径**：点"下载"列的小方框切换勾选；表头的勾选框是全部全选/取消。双击"本地保存路径"可以单独改（填文件夹会自动补上原文件名，填完整路径可以改名）；"选中项改目录…"可以批量改，并选择是否保留 HF 上的子目录结构；"恢复默认路径"撤销自定义。

**下载方式**（四个按钮）：

- **推送到 IDM** —— 公开仓库直接加入 IDM 主下载队列（可选是否自动开始）；受限/私有仓库会用 Token 换临时直链直接下载，直链约 1 小时有效，所以这类仓库要等它下完再关程序。IDM 用它自己的代理设置（IDM → 选项 → 代理服务器），选官方源时如果连不上要在 IDM 里设代理。
- **用 aria2 下载** —— 开一个黑色窗口显示 aria2 的实时输出，多线程、分块下载；"停止"可以结束它，下次再启动会自动续传。
- **用常规下载** —— 转到"常规"页用 `huggingface_hub` 下载，进度更直观；常规页正在下载时会直接加入当前任务。
- **导出 aria2 任务 / 导出 URL 列表** —— 生成文件，方便拿到别的机器或别的工具里用。

**导入导出**：`导出 CSV` / `导入 CSV`（CSV 表头：下载(1/0)、仓库、类型、分支、HF 路径、大小(字节)、本地保存路径，第一列 1/0 表示是否勾选），`导入任务…` 可以一次读入多个 aria2 任务文件或 URL 列表。

**aria2 高级设置**里有：每个文件线程数（1~16）、分块最小大小、失败重试、超时、慢速断开阈值、总/单文件限速、磁盘缓存、磁盘空间分配方式、代理（可直接用系统代理）、User-Agent、其他自定义参数，还有"一键速度最大化"和"恢复默认"。同时下载几个文件由页面上的"同时下载"控制；总连接数 = 同时下载数 × 每文件线程数，开太大容易被服务器限流（429），速度反而下降。选官方源、并且这里的代理方式是"不使用代理"时，会自动用"源"按钮检测到的代理。

**aria2 下载与使用**：单击 [aria2](https://github.com/aria2/aria2/releases) 跳转到下载页，选择自己系统位数并下载，将解压到任意磁盘，然后复制 **aria2c.exe** 文件的路径到 **aria2c** 中即可使用aria2c下载了。

## 6. 文件和配置

这些都在**程序目录**（`F:\HF下载`）下，和旧版 tkinter 程序共用：

| 文件                          | 作用                                                                                                           |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `hf_downloader_config.json` | 所有设置（Token、保存路径、下载源、筛选条件、aria2 参数、仓库列表……）                                        |
| `hf_download_history.json`  | 常规下载的历史记录（列表里的那些行）                                                                           |
| `启动日志.log`              | 每次启动的过程记录：用的哪个解释器、有没有装 huggingface_hub、端口、窗口、网页是否连上、出错时的完整堆栈       |
| `python_path.txt`           | 可选。`启动.bat` 找不到 Python 时，把 `pythonw.exe` 完整路径写在第一行                                     |
| `关于\`                     | "关于作者""关于软件"里的图文内容：`关于作者.html`、`关于软件.html`（图片也放这个文件夹，直接编辑即可生效） |
| `备份\`                     | 改动前的备份（含 `webui_<时间>\` 快照）                                                                      |

程序只监听 `127.0.0.1`（本机），端口每次随机，并且每个接口请求都要求带一个本次运行随机生成的密钥，别的网页调用不了你的本地接口。

## 8. 常见问题

**双击 `启动.bat` 没反应**
看 `启动日志.log` 的最后几行，或者双击 `诊断启动.bat` 让它把报错显示出来。日志里没有新记录，说明连 Python 都没起来 —— 检查 `python_path.txt` 里写的路径，或确认 Anaconda 装在哪个盘。

**提示"无法连接到后台"**
后台进程已经退出了（窗口关掉过、或者程序崩了）。关掉窗口重新启动即可；如果是反复出现，把 `启动日志.log` 最后的报错发出来。小圆点是灰色/红色就代表这个状态。

**提示需要 HF Token**
受限（gated）或私有仓库必须填 Token：先在 huggingface.co 上同意该仓库的协议，再到"常规下载"页填 Token（两页共用）。建议在官网建一个**只读**的 Token。

程序只在需要时才发 Token：

- **国内镜像**：一律先不带，服务器回 401 / 403 才带上 Token 重试。Token 会经过 `hf-mirror.com`，由镜像站转交官方验证，可以正常使用；
- **官方源**：只有已知是受限 / 私有仓库（批量页获取列表时就知道）才一开始就带，其余同样是 401 / 403 时才带；
- **推送到 IDM / 用 aria2 下载**：它们没法"失败了再重试"，受限 / 私有仓库的文件会直接带上 Token。

**速度上不去，或出现 429 / 频繁重连**
连接开太多了。把"常规"页的"每文件连接"或 aria2 的"每个文件线程数"降到 8，或减少"同时下载"的文件数；公开仓库一般 8~16 线程就够。总连接数 = 同时下载文件数 × 每个文件的连接数，两个都开到最大时是 16 × 16。

**进度停在某个百分比、速度变成 0**
以前单连接下载时，一条连接被服务器"晾"住就会一直停在 0 B/s；现在 ≥32MB 的文件是分段多线程下载，某条连接 20 秒收不到数据会自动断开重连、从断点续传，其余连接照常下载。小文件（<32MB）仍是单连接，真卡住了就右键"停止下载"再"继续下载"。

**下载下来的大小和 HF 网站上显示的不一样**
正常现象。HF 网站按 1 GB = 1000³ 字节算，Windows 资源管理器按 1 GB = 1024³ 字节算，同一个文件在 Windows 里显示会小约 7%，字节数完全一致。界面左下角"说明"里有对照表。

**"打开"某个文件，窗口没到前面来**
程序会在打开后主动把新窗口提到最前（置顶/取消置顶、附加前台线程、模拟 Alt 键几套办法依次尝试）。少数程序会把窗口开在自己的后台，这种情况下从任务栏切一下即可。

**IDM 里找不到刚推送的任务**
还没开始下载的队列任务，IDM 不显示大小和状态，在"全部任务"里按时间排序会排到最底部 —— 点 IDM 左侧"未完成"或用"队列 → 主要下载队列"查看。

**找不到 IDMan.exe / aria2c.exe**
在批量页底部手动选择路径。aria2 也可以直接把 `aria2c.exe` 放进程序目录，程序会自动找到它。
