这个软件是做什么的

网页界面的 Hugging Face 下载器：常规下载走官方 huggingface_hub，有逐文件进度和断点续传； 批量下载可以列出仓库里的全部文件、按条件筛选勾选，再交给 IDM 或 aria2 多线程下载。支持国内镜像、Token、历史记录。

版本说明

v1.0.0 · 2026-11-24

  • 常规下载、批量下载两个页面，共用一份配置和 Token
  • 批量页支持筛选（后缀 / 文件名 / 路径 / 大小 / 排除）、即时预览、实时勾选
  • 推送到 IDM、用 aria2 下载、转常规下载、导出 CSV / aria2 任务 / URL 列表
  • 提示改为右下角通知，不打断操作；打开文件后窗口自动置前
  • 后台随窗口在线，关窗口才退出；启动失败会写日志并弹提示
